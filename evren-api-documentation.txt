GET /v1/terms/status → yanıttaki current_version sayısını not edin

GET /v1/terms/text ile metni okuyun

POST /v1/terms/accept gövdesine az önce not ettiğiniz sayıyı yazın: {"version": <1. adımdaki sayı>}

Hesap başına bir kez gerekir - yeni esaslı sürüm yayınlanmadıkça tekrar istenmez. Bu adımı atlarsanız 403 terms_not_accepted alırsınız. Test Alanı'ndaki anahtar kutusu bu üç adımı tek tıkla yapar.

Önemli Kural: DeepSeek ve Qwen akıl yürütme modellerinde düşünme ve nihai yanıt bütçesi ortaktır (max_tokens). Bütçenin düşünme aşamasında tükenmemesi için max_tokens asgari 2048 (önerilen: 4096) girilmelidir. Akışta düşünme token'ları delta.reasoning veya delta.reasoning_content ile iletilir.
cURL Akış (SSE) İstek Örneği (bash)

curl -N "https://evren-llmapi.ssyz.org.tr/v1/chat/completions" \
  -H "Authorization: Bearer $EVREN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4.1-flash",
    "messages": [{"role": "user", "content": "Algoritmanın karmaşıklığını ve adımlarını açıkla."}],
    "max_tokens": 4096,
    "stream": true,
    "stream_options": {"include_usage": true}
  }'
Python OpenAI SDK — Düşünme Ayrıştırma (python)

from openai import OpenAI

client = OpenAI(base_url="https://evren-llmapi.ssyz.org.tr/v1", api_key="evren_llm_...")

stream = client.chat.completions.create(
    model="deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "Adımları gerekçelendir."}],
    max_tokens=4096,
    stream=True,
)

for chunk in stream:
    delta = chunk.choices[0].delta if chunk.choices else None
    if not delta:
        continue
    # Muhakeme aşaması: delta.reasoning veya delta.reasoning_content
    reasoning = getattr(delta, "reasoning", None) or getattr(delta, "reasoning_content", None)
    if reasoning:
        print(f"[Düşünme]: {reasoning}", end="", flush=True)
    if delta.content:
        print(delta.content, end="", flush=True)
Geliştirici Teknik Sözleşmesi ve Kritik İlkeler
Akıl Yürütme ve Bütçe
max_tokens ≥ 2048
Ortak Token Havuzu: DeepSeek ve Qwen gibi akıl yürüten modellerde max_tokens değeri hem düşünme hem de nihai yanıt için ortak kullanılır. Yanıtın yarım kalmaması için bu değeri en az 2048 (önerilen: 4096) olarak belirleyin.

Düşünme Akışı: Modelin iç muhakeme süreci delta.reasoning alanı üzerinden iletilir; resmi OpenAI kütüphaneleri bu alanı otomatik olarak ayrıştırır.

Hız Sınırları ve Kotalar
15M Günlük · 500k TPM
15 Milyon Günlük Kota: Hesabınıza günlük 15.000.000 token ücretsiz tanımlanır (1 Kasım tarihine kadar). Bu kota LLM, OCR, embedding, rerank ve Laya dahil tüm modellerin ve tüm API anahtarlarınızın toplamıdır; yeni anahtar oluşturmak kotayı artırmaz. (HTTP 429 hesap kotasını, 503 anlık sunucu doluluğunu belirtir.)

Kalan Kota: Günlük kalan tokenı ve sıfırlanma zamanını aynı API anahtarıyla GET /v1/quota ucundan okuyabilirsiniz. Bu değerler her yanıtta x-evren-daily-remaining-tokens başlığıyla da gelir.

Dakikada 500k Token: Normal hız sınırı 500k TPM'dir. Ancak DeepSeek (1M) gibi modellerde tek seferde gönderilen 500k üzeri devasa analiz istekleri engellenmeden kabul edilir.

Kısa Bekleme: Dakikalık limitiniz dolsa bile sistem hesabınızı kilitlemez; bekleme süresi en fazla 60 saniyedir.

Önbellek İndirimi: Ajan araçlarının (Cline, opencode, Codex) her turda yeniden gönderdiği bağlam sunucu önbelleğinden okunur. Önbellekten gelen girdi token'ları kotaya %3 ağırlıkla yazılır; kullanım sayfasındaki "Önbellekten" ve "Kotaya yansıyan" sütunlarında görebilirsiniz. İsteklerinizin başını (sistem istemi, araç tanımları) sabit tutmak önbellek oranını artırır.

Kesintisiz Akış & Heartbeat
: keep-alive (10s)
Bağlantı Koruma: Model uzun süre düşünürken aradaki proxy ve ağ bağlantılarının kopmaması için sunucu her 10 saniyede bir : keep-alive sinyali gönderir.

İstemci Ayarı: Kendi SSE istemcinizi geliştiriyorsanız, iki nokta (:) ile başlayan bu yorum satırlarını JSON ayrıştırmasına sokmadan doğrudan atlayın.

Uç noktalar ve model seçimi

model alanına aşağıdaki tablodaki api_name değerlerinden birini yazın. Her satırın sağındaki ⓘ ikonu o modele ait kod örneklerini açar.

Model seçmek istemiyorsanız "auto" yazın — gateway isteği aday havuzundaki uygun modele yönlendirir. Bu bir model değil, yönlendirme kipidir; bu yüzden aşağıdaki tabloda listelenmez.

OpenAI API Uyumluluğu
EVREN LLM API, OpenAI'nin yayınladığı REST sözleşmesini (istek/yanıt şeması, hata gövdesi, akış çerçevesi) uygular. Bu sayede resmi openai SDK'ları (Python, Node.js, Go, Java, .NET) hiçbir kod değişikliği gerektirmeden çalışır - tek yapmanız gereken base_url ve api_key alanlarını kurumunuza tanımlı değerlerle değiştirmektir.

from openai import OpenAI

client = OpenAI(
    base_url="https://evren-llmapi.ssyz.org.tr/v1",
    api_key="evren_llm_...",
)
response = client.chat.completions.create(model="auto", messages=[...])
Desteklenen uçlar

Örnek curl için uç kartına tıklayın

/v1/chat/completions
Sohbet tamamlama - streaming (SSE) dahil

/v1/responses
OpenAI'nin yeni Responses API şekli (Codex CLI)

/v1/ocr
Belge ve taranmış sayfa OCR çıkarımı (dots-ocr, deepseek-ocr-2)

/v1/audio/transcriptions
Ses → metin (Whisper uyumlu istek şekli)

/v1/embeddings
Metin gömme vektörü üretimi

/v1/rerank
Belge yeniden sıralama - OpenAI'de yok, Cohere/Jina sözleşmesiyle uyumlu

/v1/systemone
Tipli karar (choice / score / noul) - OpenAI'de yok, Jev sözleşmesiyle uyumlu

/v1/models
Hesaba tanımlı model kataloğu ve fiyatlandırma
Kimlik doğrulama: hem SDK'ların otomatik gönderdiği Authorization: Bearer <anahtar> başlığı hem de düz X-API-Key başlığı kabul edilir.
Akış (streaming): stream: true ile standart text/event-stream (SSE) çerçevesi döner - SDK'nın kendi akış iteratörü doğrudan çalışır.
EVREN'e özgü genişletmeler

Aşağıdakiler OpenAI sözleşmesinin üzerine eklenen, standart SDK davranışını bozmayan ek bilgi alanlarıdır - resmi SDK'lar hangi istisnanın fırlatılacağına sadece HTTP durum koduna bakarak karar verir, bu ek alanları sessizce yok sayar.

error.evren
Hata gövdesinde ek alt-alan (kalan kota, alternatif model, kabul edilmesi gereken sürüm). Resmi SDK'lar bu alanı YOK SAYAR, akışı bozmaz.
X-Evren-Credits-*
Yanıt başlıklarında HOLD/kalan bakiye bilgisi - kredi ekonomisinin şeffaflığı için.
Kullanım şartları kapısı
İlk çağrıdan önce tek seferlik onay gerektirir (yukarıdaki adım 2) - OpenAI'nin sözleşmesinde karşılığı yoktur, EVREN'e özgüdür.
